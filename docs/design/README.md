# 设计稿（Design study）

`preview.html` 是发布前做的**视觉研究稿**：单文件、零依赖，双击即可打开；`?theme=ink` 切深色；顶部可调气泡圆角/尖角/深浅。

它和**真正发布的面板**有两处刻意的差别：

| | 设计稿 | 发布版 `lib/client.js` |
|---|---|---|
| 配色 | 自带「纸白 / 夜墨」两套主题 | 直接使用 DSH 的主题变量（`--dsw-alias-*`），跟随用户当前明暗 |
| 偏好 | 面板内的滑杆（演示用，不持久化） | 翻译档位/双语/展开状态写入 `localStorage` |

## 从设计稿留下来的结论

- 用户发言放右侧、思考步骤放左侧卡片，**不显示头像**；
- 气泡与背景要分层，但浅色系里气泡只比面板深一档、深色系里反过来，避免高对比；
- 顶部定位条**横向滚动**：滚轮可滚、两端渐隐、到边收箭头；右侧迷你地图默认收成一枚窄把手；
- 历史必须能独立加载（「载入更早」+ 按轮搜索），不依赖对话区的滚动；
- **不要**用 `backdrop-filter`（磨砂）：纯色底上没有可模糊的内容，做了也看不出来，已从发布版移除；
- 字号 12–13px、正文对比度 ≥ 4.5:1，辅助文字 10.5–11.5px。
